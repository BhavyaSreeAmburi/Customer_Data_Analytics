Customer Data Analysis Using Python

Project Overview

This project analyzes customer purchase data using Python. The dataset is processed and analyzed to identify customer purchasing patterns and generate useful business insights.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib

Dataset

The dataset contains the following information:

- Customer ID
- Customer Name
- Age
- Gender
- City
- Product
- Purchase Amount

Analysis Performed

- Checked for missing values
- Analyzed average purchase amount
- Calculated total purchase amount
- Identified highest and lowest purchase amounts
- Performed product-wise sales analysis
- Performed city-wise sales analysis
- Compared purchase amounts by gender

Visualizations

- Product-wise Total Sales Bar Chart
- City-wise Total Sales Bar Chart
- Gender-wise Total Purchase Bar Chart

Key Insights

The analysis identifies:

- Top-selling product
- Best-performing city
- Customer with the highest purchase amount
- Average customer purchase amount

How to Run the Project

1. Install the required libraries:

pip install pandas numpy matplotlib

2. Run the Python file:

python Customer_Data_Analysis.py
